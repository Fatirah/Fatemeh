# پروژه ربات خودکار کیبورد (Auto Typer)

این پروژه یک ربات ساده است که با استفاده از کتابخانه PyAutoGUI، به‌طور خودکار شروع به تایپ پیام در هر محیطی (مثل نوت‌پد، مرورگر، پیام‌رسان و ...) می‌کند.

---

## 📌 کاربرد پروژه
- آشنایی با اتوماسیون صفحه‌کلید و ماوس در پایتون
- اجرای عملیات تکراری به‌صورت خودکار
- شبیه‌سازی تایپ کردن توسط کاربر

---

## ✨ امکانات
- تأخیر ۳ ثانیه‌ای قبل از شروع (برای آماده شدن)
- تایپ یک پیام خوش‌آمدگویی (مثلاً `salam`)
- تایپ مکرر یک عبارت (`I love you!`) به تعداد مشخص (۱۰ بار)
- فاصله‌گذاری بین حروف هنگام تایپ (نمایش واقع‌گرایانه)
- فشار دادن کلید Enter بعد از هر بار تایپ

---

## 📚 کتابخانه‌های استفاده شده
- `pyautogui` – برای شبیه‌سازی کیبورد و ماوس
- `time` – برای ایجاد تأخیر بین اقدامات

---

## 🚀 نحوه اجرا
1. کتابخانه PyAutoGUI را نصب کنید:
   
   pip install pyautogui
