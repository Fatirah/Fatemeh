# پروژه 24: پردازش تصویر با OpenCV و ابزارهای هوش مصنوعی

این پروژه شامل عملیات‌های پایه‌ای پردازش تصویر با استفاده از کتابخانه OpenCV است.

---

## 📌 کاربرد پروژه
- بارگذاری و نمایش تصاویر
- تبدیل رنگ‌ها (BGR به RGB)
- برش تصویر (Cropping)
- تغییر اندازه تصویر (Resize)
- تبدیل به تصویر خاکستری
- آستانه‌گذاری (Thresholding)
- نوشتن متن روی تصویر
- رسم اشکال (مستطیل)
- ذخیره تصویر

---

## ✨ امکانات
- تبدیل BGR به RGB برای نمایش صحیح رنگ‌ها
- برش بخش‌های دلخواه از تصویر
- تغییر اندازه تصویر با روش‌های مختلف
- تبدیل تصویر به خاکستری
- آستانه‌گذاری باینری (Thresholding)
- اضافه کردن متن و رسم مستطیل
- نمایش تصاویر در پنجره جداگانه با OpenCV

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `opencv-python` (cv2) | پردازش تصویر |
| `matplotlib` | نمایش تصاویر |
