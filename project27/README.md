# پروژه پردازش صدا و ابزارهای هوش مصنوعی (پروژه 27)

این پروژه شامل عملیات‌های پایه‌ای پردازش صدا با استفاده از کتابخانه‌های `pyaudio` و `numpy` است.

---

## 📌 کاربرد پروژه
- ضبط صدا از میکروفون
- ذخیره و نمایش داده‌های صوتی
- پخش صدای ضبط شده
- کاهش نویز و هموارسازی صدا
- تحلیل سیگنال با استفاده از FFT و اسپکتروگرام

---

## ✨ امکانات
- ضبط صدای زنده با فرمت ۱۶ بیتی
- نمایش شکل‌موج (Waveform) صدا
- پخش صدای ضبط شده
- کاهش دامنه صدا (کاهش حجم)
- حذف بخش‌های بی‌صدای ابتدا و انتها
- حذف نویزهای کم‌دامنه با آستانه‌گذاری
- تحلیل فرکانسی با FFT
- نمایش اسپکتروگرام صدا

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `pyaudio` | ضبط و پخش صدا |
| `numpy` | پردازش عددی داده‌های صوتی |
| `matplotlib` | رسم نمودارها و نمایش داده‌ها |

---
