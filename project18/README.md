# پروژه اتصال به API هوش مصنوعی (GPT-4o)

این پروژه یک اتصال ساده به API هوش مصنوعی با استفاده از کتابخانه رسمی OpenAI است که امکان دریافت پاسخ از مدل `gpt-4o` را فراهم می‌کند.

---

## 📌 کاربرد پروژه
- آشنایی با نحوه اتصال به APIهای هوش مصنوعی
- دریافت پاسخ از مدل‌های زبانی بزرگ (LLM)
- استفاده از کلید API و آدرس پایه سفارشی

---

## ✨ امکانات
- اتصال به API از طریق کتابخانه `OpenAI`
- ارسال سوال به مدل `gpt-4o`
- تنظیم پارامترهای `max_tokens` و `temperature`
- نمایش پاسخ دریافتی از مدل
- مدیریت خطا در صورت بروز مشکل

---
