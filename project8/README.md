# پروژه ساخت QR Code

این پروژه شامل ساخت کدهای QR برای اطلاعات مختلف مانند شماره تلفن (با قابلیت ارسال SMS)، اتصال به Wi-Fi، لینک تلگرام و واتساپ است.

---

## 📌 کاربرد پروژه
- ساخت کد QR برای اشتراک‌گذاری آسان اطلاعات
- اتصال سریع به Wi-Fi بدون نیاز به وارد کردن رمز
- اشتراک‌گذاری لینک شبکه‌های اجتماعی
- ارسال پیامک با اسکن کد QR

---

## ✨ امکانات
- ساخت QR Code برای شماره تلفن (با قابلیت ارسال SMS)
- ساخت QR Code برای اتصال خودکار به Wi-Fi
- ساخت QR Code برای لینک تلگرام
- ساخت QR Code برای لینک واتساپ

---

## 📚 کتابخانه‌های استفاده شده
- `qrcode` – برای تولید کدهای QR

---

## 🚀 نحوه اجرا
1. کتابخانه qrcode را نصب کنید:
   
   pip install qrcode
