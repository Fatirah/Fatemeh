# پروژه هشدار و پیش‌بینی آب‌وهوا

این پروژه با استفاده از API سایت OpenWeatherMap، اطلاعات آب‌وهوای لحظه‌ای را دریافت کرده و در صورت بالا بودن دما، هشدار صوتی (بوق) پخش می‌کند.

---

## 📌 کاربرد پروژه
- دریافت اطلاعات آب‌وهوای لحظه‌ای هر شهر در جهان
- نمایش دما، مختصات و سایر اطلاعات آب‌وهوا
- مقایسه دمای فعلی با دمای آستانه (مثلاً ۳۰ درجه)
- پخش صدای هشدار در صورت گرم بودن هوا

---

## ✨ امکانات
- دریافت دمای فعلی برای هر شهر
- نمایش کامل اطلاعات آب‌وهوا (پاسخ JSON)
- تنظیم دمای آستانه دلخواه
- پخش صدای بوق به عنوان هشدار در صورت گرم شدن هوا
- پشتیبانی از ورودی شهر توسط کاربر

---

## 📚 کتابخانه‌های استفاده شده
- `requests` – برای ارسال درخواست به API
- `json` – برای پردازش پاسخ دریافتی
- `winsound` – برای پخش صدای بوق (فقط در ویندوز)

---

## 🚀 نحوه اجرا
1. فایل `havashenasi.ipynb` را در Jupyter باز کنید.
2. سلول‌ها را به ترتیب اجرا کنید.
3. نام شهر مورد نظر را به انگلیسی وارد کنید (مثلاً `Tehran` یا `London`).
4. دمای فعلی و وضعیت آب‌وهوا نمایش داده می‌شود.
5. اگر دما از حد آستانه (مثلاً ۳۰ درجه) بیشتر باشد، صدای بوق پخش می‌شود.
