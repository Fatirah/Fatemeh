# پروژه تشخیص دیابت با استفاده از Logistic Regression

این پروژه یک مدل یادگیری ماشین برای پیش‌بینی ابتلا به دیابت بر اساس داده‌های پزشکی است.

---

## 📌 کاربرد پروژه
- پیش‌بینی ابتلا به دیابت با استفاده از داده‌های پزشکی
- آشنایی با مفاهیم طبقه‌بندی (Classification)
- پیاده‌سازی مدل Logistic Regression

---

## ✨ امکانات
- بارگذاری و بررسی دیتاست دیابت
- نمایش آمار توصیفی داده‌ها
- جدا کردن ویژگی‌ها و هدف
- تقسیم داده‌ها به آموزش و تست
- آموزش مدل Logistic Regression
- ارزیابی مدل با محاسبه خطا و دقت
- تست مدل روی یک نمونه جدید

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `pandas` | پردازش داده‌ها |
| `numpy` | محاسبات عددی |
| `scikit-learn` | مدل‌سازی و ارزیابی |

---

## 📊 ساختار دیتاست (diabetes.csv)
- تعداد نمونه‌ ها:392
- تعداد ویژگی‌ها: ۸
- ویژگی‌ها:
  - `Pregnancies` – تعداد بارداری‌ها
  - `Glucose` – سطح گلوکز
  - `BloodPressure` – فشار خون
  - `SkinThickness` – ضخامت پوست
  - `Insulin` – سطح انسولین
  - `BMI` – شاخص توده بدنی
  - `DiabetesPedigreeFunction` – سابقه خانوادگی دیابت
  - `Age` – سن
- هدف (`Outcome`): ۰ = بدون دیابت, ۱ = مبتلا به دیابت
