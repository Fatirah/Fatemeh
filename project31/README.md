# پروژه تشخیص پلاک خودرو با استفاده از Logistic Regression

این پروژه با استفاده از پردازش تصویر و مدل رگرسیون لجستیک، کاراکترهای پلاک خودرو را تشخیص داده و شماره پلاک را به صورت کامل استخراج می‌کند.

---

## 📌 کاربرد پروژه
- تشخیص خودکار شماره پلاک خودرو از روی تصویر
- جداسازی کاراکترهای پلاک با استفاده از پردازش تصویر
- شناسایی کاراکترها با استفاده از Logistic Regression

---

## ✨ امکانات
- تبدیل تصاویر به بردار ویژگی (Flatten)
- تغییر اندازه تصاویر به ۸×۳۲ برای نرمالایز کردن
- ساخت دیتاست از تصاویر کاراکترها
- آموزش مدل Logistic Regression روی کاراکترها
- تشخیص کاراکترها در تصویر پلاک با استفاده از پروفایل ستونی
- رسم مستطیل دور هر کاراکتر در پلاک
- نمایش شماره پلاک تشخیص داده شده روی تصویر

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `opencv-python` (cv2) | پردازش تصویر و تشخیص کاراکترها |
| `numpy` | محاسبات عددی |
| `sklearn` | مدل‌سازی و تقسیم داده‌ها |
| `os` | کار با فایل‌ها و پوشه‌ها |
