# پروژه ردیابی چهره و کنترل موس با OpenCV و PyAutoGUI

این پروژه با استفاده از دوربین وب‌کم، چهره کاربر را تشخیص داده و بر اساس حرکت سر، موس کامپیوتر را کنترل می‌کند.

---

## 📌 کاربرد پروژه
- کنترل کامپیوتر بدون استفاده از دست (با حرکت سر)
- مناسب برای افراد دارای معلولیت
- آشنایی با پردازش تصویر و بینایی ماشین
- ترکیب OpenCV و PyAutoGUI برای کاربردهای واقعی

---

## ✨ امکانات
- تشخیص چهره با استفاده از Haar Cascade
- تشخیص چشم‌ها در تصویر
- رسم مستطیل دور چهره (سبز) و چشم‌ها (قرمز)
- حرکت موس بر اساس موقعیت چهره:
  - حرکت به چپ/راست با تغییر موقعیت افقی چهره
  - حرکت به بالا/پایین با تغییر موقعیت عمودی چهره
- نمایش ناحیه فعال با مستطیل آبی/سفید
- خروج از برنامه با کلید `q`

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `opencv-python` (cv2) | پردازش تصویر و تشخیص چهره |
| `pyautogui` | کنترل موس و صفحه کلید |
| `numpy` | پردازش عددی داده‌ها |

---
