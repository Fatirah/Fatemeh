# پروژه تبدیل گفتار به متن، ترجمه و تبدیل به گفتار (Speech-to-Text + Translation + Text-to-Speech)

این پروژه یک ابزار هوشمند است که با استفاده از کتابخانه‌های `speech_recognition`، `deep_translator` و `pyttsx3`، گفتار کاربر را دریافت، به انگلیسی ترجمه و سپس به صورت گفتار (صدا) پخش می‌کند.

---

## 📌 کاربرد پروژه
- دریافت صدای کاربر از طریق میکروفون
- تشخیص گفتار و تبدیل آن به متن (فارسی)
- ترجمه متن تشخیص داده شده به انگلیسی
- تبدیل متن ترجمه شده به گفتار (صدا) و پخش آن

---

## ✨ امکانات
- تشخیص گفتار با استفاده از سرویس Google Speech Recognition
- ترجمه خودکار متن از فارسی به انگلیسی
- تبدیل متن به گفتار با قابلیت تنظیم صدا و سرعت
- انتخاب صدای مختلف (مردانه/زنانه)
- پخش صدای خروجی به صورت بلندگو

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `speech_recognition` | تشخیص و تبدیل گفتار به متن |
| `deep_translator` | ترجمه متن با استفاده از Google Translate |
| `pyttsx3` | تبدیل متن به گفتار (Text-to-Speech) |

---

## 🚀 نحوه اجرا
1. کتابخانه‌های مورد نیاز را نصب کنید:
   
   pip install SpeechRecognition pyaudio deep-translator pyttsx3
