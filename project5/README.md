# پروژه سنگ، کاغذ، قیچی (Rock, Paper, Scissors)

این پروژه یک بازی ساده‌ی سنگ-کاغذ-قیچی است که کاربر مقابل کامپیوتر بازی می‌کند.

---

## 📌 کاربرد پروژه
- ایجاد یک بازی تعاملی برای سرگرمی
- آشنایی با مفهوم تولید اعداد تصادفی در پایتون
- تمرین شرط‌ها و حلقه‌ها در برنامه‌نویسی

---

## ✨ امکانات
- دریافت انتخاب کاربر (سنگ، کاغذ یا قیچی)
- انتخاب تصادفی توسط کامپیوتر با استفاده از `random`
- تعیین برنده در هر دور
- نمایش امتیاز نهایی پس از چند دور

---

## 📚 کتابخانه‌های استفاده شده
- `random` – برای انتخاب تصادفی کامپیوتر
