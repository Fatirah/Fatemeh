# پروژه تشخیص پلاک خودرو با استفاده از Logistic Regression

این پروژه با استفاده از پردازش تصویر و مدل رگرسیون لجستیک، پلاک خودرو را تشخیص می‌دهد.

---

## 📌 کاربرد پروژه
- تشخیص پلاک خودرو از روی تصاویر
- تبدیل تصاویر به بردار ویژگی
- طبقه‌بندی تصاویر با Logistic Regression
- تست مدل روی تصاویر جدید

---

## ✨ امکانات
- بارگذاری و نمایش تصاویر
- تغییر اندازه تصاویر به ۸×۳۲ (نرمالایز کردن)
- تبدیل به تصویر خاکستری
- تبدیل تصویر به بردار یک‌بعدی (Flatten)
- ساخت دیتاست از دو پوشه (۱ و ۲)
- آموزش مدل رگرسیون لجستیک
- تست مدل روی تصویر جدید
