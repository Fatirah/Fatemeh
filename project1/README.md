# پروژه تبدیل سن به زمان (Age to Time Converter)

این برنامه یک ابزار ساده است که **سن شما را بر حسب سال** گرفته و آن را به **ماه، روز، ساعت و ثانیه** تبدیل می‌کند. همچنین سال تولد و تعداد سال‌های کبیسه را محاسبه می‌کند.

---

## 📌 کاربرد پروژه
- محاسبه دقیق سن به واحدهای مختلف زمان
- تشخیص سال‌های کبیسه
- محاسبه سال تولد
- نمایش تعداد روزهای هر ماه با در نظر گرفتن کبیسه بودن سال

---

## ✨ امکانات
- دریافت سن از کاربر
- تبدیل سن به:
  - سال
  - ماه
  - روز
  - ساعت
  - ثانیه
- تشخیص سال کبیسه با استفاده از `calendar`
- محاسبه سال تولد
- شمارش تعداد سال‌های کبیسه

---

## 📚 کتابخانه‌های استفاده شده
- `time` – برای دریافت زمان جاری سیستم
- `calendar` – برای تشخیص سال کبیسه

---

## 🚀 نحوه اجرا
1. فایل `project1 Time Age.ipynb` را در Jupyter باز کنید.
2. سلول‌ها را به ترتیب اجرا کنید.
3. سن خود را بر حسب سال وارد کنید.
4. نتیجه را مشاهده کنید.
