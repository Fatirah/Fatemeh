# پروژه 28: تشخیص چهره با استفاده از face_recognition

این پروژه با استفاده از کتابخانه `face_recognition`، موقعیت چهره را در تصویر تشخیص داده، مستطیل دور آن رسم کرده و سپس با مقایسه ویژگی‌های چهره، تشخیص می‌دهد که آیا دو تصویر متعلق به یک شخص هستند یا خیر.

---

## 📌 کاربرد پروژه
- تشخیص موقعیت چهره در تصویر
- نمایش تصویر با OpenCV
- استخراج ویژگی‌های چهره (Face Encoding)
- مقایسه دو چهره و تشخیص شباهت

---

## ✨ امکانات
- تشخیص چهره با استفاده از `face_recognition`
- نمایش تصویر با OpenCV
- تبدیل BGR به RGB برای نمایش صحیح رنگ‌ها
- رسم مستطیل دور چهره تشخیص داده شده
- استخراج بردار ویژگی ۱۲۸ عنصری هر چهره
- مقایسه دو چهره و تشخیص هویت

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `face_recognition` | تشخیص چهره و استخراج ویژگی‌ها |
| `opencv-python` (cv2) | نمایش و پردازش تصویر |
| `dlib` | پشتیبان تشخیص چهره |
| `numpy` | پردازش عددی داده‌ها |
