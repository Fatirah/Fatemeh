# پروژه پردازش تصویر با استفاده از NumPy و PIL

این پروژه شامل مفاهیم اولیه پردازش تصویر با استفاده از کتابخانه‌های NumPy و PIL در پایتون است. در این پروژه، یک تصویر بارگذاری شده و با استفاده از آرایه‌ها، تغییرات روی پیکسل‌های آن اعمال می‌شود.

---

## 📌 کاربرد پروژه
- آشنایی با آرایه‌های چندبعدی در NumPy
- بارگذاری و نمایش تصاویر با PIL
- دسترسی و تغییر پیکسل‌های تصویر
- آشنایی با نمایش تصاویر با Matplotlib

---

## ✨ امکانات
- ایجاد آرایه‌های یک‌بعدی و دو‌بعدی با NumPy
- بارگذاری تصویر با فرمت BMP
- نمایش تصویر با استفاده از Matplotlib
- دسترسی به پیکسل‌ها و تغییر مقادیر RGB آنها
- ترسیم خط‌های رنگی روی تصویر با تغییر پیکسل‌ها

---

## 📚 کتابخانه‌های استفاده شده
- `numpy` – برای کار با آرایه‌ها و ماتریس‌ها
- `PIL` (Pillow) – برای بارگذاری و پردازش تصویر
- `matplotlib.pyplot` – برای نمایش تصویر

---
