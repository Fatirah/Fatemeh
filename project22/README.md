# پروژه ترجمه و باز کردن برنامه‌ها با دستور صوتی (Google Translate & Voice Commands)

این پروژه یک ابزار هوشمند است که با استفاده از کتابخانه‌های `deep_translator` و `speech_recognition`، قابلیت ترجمه متن و اجرای دستورات صوتی مانند باز کردن برنامه‌ها را فراهم می‌کند.

---

## 📌 کاربرد پروژه
- ترجمه متون فارسی به انگلیسی با استفاده از Google Translator
- تشخیص گفتار و تبدیل آن به متن
- اجرای دستورات صوتی برای باز کردن برنامه‌ها (مانند گوگل کروم)

---

## ✨ امکانات
- ترجمه خودکار متن با تشخیص زبان مبدأ
- تشخیص گفتار زنده از طریق میکروفون
- اجرای دستورات صوتی مانند «گوگل کروم باز»
- باز کردن مرورگر گوگل کروم با دستور صوتی

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `deep_translator` | ترجمه متن با استفاده از Google Translate |
| `speech_recognition` | تشخیص و تبدیل گفتار به متن |
| `os` | اجرای دستورات سیستمی برای باز کردن برنامه‌ها |

---

## 🚀 نحوه اجرا
1. کتابخانه‌های مورد نیاز را نصب کنید:
   
   pip install deep-translator SpeechRecognition pyaudio
