# پروژه تشخیص ارقام دست‌نویس با Logistic Regression

این پروژه شامل پیاده‌سازی یک مدل یادگیری ماشین برای تشخیص ارقام دست‌نویس (۰ تا ۹) با استفاده از رگرسیون لجستیک است. داده‌های مورد استفاده از مجموعه داده‌های `digits` در کتابخانه `scikit-learn` گرفته شده است.

---

## 📌 کاربرد پروژه
- تشخیص خودکار ارقام دست‌نویس
- آشنایی با مفاهیم طبقه‌بندی (Classification) در یادگیری ماشین
- ارزیابی عملکرد مدل با معیار دقت (Accuracy)

---

## ✨ امکانات
- بارگذاری دیتاست ارقام دست‌نویس
- نمایش اطلاعات و تصاویر داده‌ها
- آموزش مدل Logistic Regression برای تشخیص ارقام ۰ تا ۹
- آموزش مدل برای تشخیص فقط دو رقم ۰ و ۱
- محاسبه دقت مدل و نمایش خطاها

---

## 📚 کتابخانه‌های استفاده شده
- `numpy` – برای محاسبات عددی
- `pandas` – برای پردازش داده‌ها
- `matplotlib` – برای نمایش تصاویر
- `seaborn` – برای رسم نمودارهای آماری
- `scikit-learn` – برای مدل‌سازی و ارزیابی
  - `datasets` – برای بارگذاری داده‌های digits
  - `LogisticRegression` – مدل رگرسیون لجستیک
  - `train_test_split` – تقسیم داده‌ها
