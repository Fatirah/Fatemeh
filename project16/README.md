# پروژه 16: تشخیص مربع و دایره با استفاده از Classification

این پروژه یک مدل یادگیری ماشین برای تشخیص اشکال مربع و دایره از روی تصاویر ۶۴×۶۴ پیکسلی است.

---

## 📌 کاربرد پروژه
- تشخیص خودکار اشکال هندسی (مربع و دایره)
- آشنایی با پردازش تصویر و استخراج ویژگی
- پیاده‌سازی یک طبقه‌بند Logistic Regression

---

## ✨ امکانات
- بارگذاری و نمایش تصاویر
- تبدیل تصاویر رنگی به خاکستری (کانال اول)
- تبدیل تصویر به بردار ویژگی (۴۰۹۶ عنصر)
- نرمال‌سازی داده‌ها (تقسیم بر ۲۵۵)
- ساخت دیتاست از ۲۰ تصویر
- آموزش مدل Logistic Regression
- ارزیابی مدل با دقت (Accuracy)
- تست مدل روی یک تصویر جدید

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `numpy` | محاسبات عددی |
| `pandas` | پردازش داده‌ها |
| `matplotlib` | نمایش تصاویر و نمودارها |
| `seaborn` | زیباسازی نمودارها |
| `scikit-learn` | مدل‌سازی و ارزیابی |
| `PIL` | پردازش تصویر |

---

## 📊 ساختار دیتاست
- تعداد تصاویر: ۲۰
- ابعاد هر تصویر: ۶۴×۶۴ پیکسل
- تعداد کانال‌ها: ۳ (RGB) → تبدیل به ۱ (خاکستری)
- تعداد ویژگی‌ها: ۴۰۹۶ (۶۴×۶۴)
- برچسب‌ها: ۰ = مربع, ۱ = دایره
