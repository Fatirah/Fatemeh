# پروژه تبدیل گفتار به متن و اتصال به GPT-4o

این پروژه ترکیبی از دو ابزار هوش مصنوعی است:  
۱. تبدیل گفتار به متن (Speech to Text) با استفاده از کتابخانه `speech_recognition`  
۲. دریافت پاسخ هوشمند از مدل `GPT-4o` بر اساس متن تشخیص داده شده

---

## 📌 کاربرد پروژه
- تبدیل صدای کاربر به متن
- تشخیص دستورات صوتی (روشن/خاموش کردن لامپ)
- ارسال متن تشخیص داده شده به API هوش مصنوعی و دریافت پاسخ
- ذخیره متن در فایل

---

## ✨ امکانات
- تبدیل فایل صوتی (WAV) به متن
- تبدیل گفتار زنده (از میکروفون) به متن
- تشخیص دستورات «لامپ روشن» و «لامپ خاموش»
- ذخیره متن تشخیص داده شده در فایل `stt.txt`
- اتصال به API مدل `gpt-4o` و دریافت پاسخ هوشمند

---

## 📚 کتابخانه‌های استفاده شده
| کتابخانه | کاربرد |
|----------|--------|
| `speech_recognition` | تشخیص و تبدیل گفتار به متن |
| `openai` | ارتباط با API هوش مصنوعی |

---

## 🚀 نحوه اجرا
